persistir en un checkout local están excluidos de Git y no deben ejecutarse.

ni instrucciones de recuperación. No se incluyen comandos de ejecución.

Cualquier intervención futura requiere un alcance nuevo, una revisión propia
y autorización expresa. La autorización de CPREN-93 quedó consumida por la
operación concluida y no habilita reutilizar sus contratos o scripts.
